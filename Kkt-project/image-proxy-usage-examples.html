🖼️ Image Proxy Usage Examples

This page shows exactly where and how to replace Firebase Storage URLs with the image proxy URLs in your Auric Jewelry website.

📍 Where to Replace URLs

In your current code, product images are loaded from Firebase Storage in these locations:

1. Product Data (JSON files)

❌ Before (Direct Firebase URLs)

{ "id": "RING-001", "name": "Diamond Ring", "price": 25000, "image": "https://firebasestorage.googleapis.com/v0/b/auric-a0c92.firebasestorage.app/o/productImages%2Fring-001.jpg?alt=media&token=abc123" }

✅ After (Image Proxy URLs)

{ "id": "RING-001", "name": "Diamond Ring", "price": 25000, "image": "/.netlify/functions/image-proxy?path=productImages/ring-001.jpg" }

2. Admin Panel (Adding New Products)

❌ Before (Direct Firebase URLs)

// In admin-panel.html const downloadURL = await storageRef.getDownloadURL(); product.image = downloadURL;

✅ After (Image Proxy URLs)

// In admin-panel.html const imagePath = `productImages/${fileName}`; product.image = `/.netlify/functions/image-proxy?path=${imagePath}`;

3. JavaScript Product Display

❌ Before (Direct Firebase URLs)

// When displaying products productElement.innerHTML = ` <img src="${product.image}" alt="${product.name}"> `; // product.image contains direct Firebase URL

✅ After (Image Proxy URLs)

// When displaying products productElement.innerHTML = ` <img src="${product.image}" alt="${product.name}"> `; // product.image contains proxy URL

🔧 Implementation Helper Function

Add this helper function to your JavaScript code to easily generate proxy URLs:

// Helper function to generate image proxy URLs function getImageProxyUrl(imagePath) { // Remove any existing Firebase Storage URL parts const cleanPath = imagePath.replace(/^https:\/\/firebasestorage\.googleapis\.com.*?\/o\//, '') .replace(/\?.*$/, '') .replace(/%2F/g, '/'); return `/.netlify/functions/image-proxy?path=${encodeURIComponent(cleanPath)}`; } // Usage examples: const proxyUrl1 = getImageProxyUrl('productImages/ring-001.jpg'); const proxyUrl2 = getImageProxyUrl('https://firebasestorage.googleapis.com/v0/b/bucket/o/productImages%2Fring-001.jpg?alt=media'); // Both return: /.netlify/functions/image-proxy?path=productImages%2Fring-001.jpg

📋 Step-by-Step Migration

Follow these steps to migrate your existing product images:

Step 1: Update Admin Panel

When adding new products, store proxy URLs instead of direct Firebase URLs:

// In your admin panel JavaScript // OLD WAY: const downloadURL = await storageRef.getDownloadURL(); newProduct.image = downloadURL; // NEW WAY: const imagePath = `productImages/${fileName}`; newProduct.image = `/.netlify/functions/image-proxy?path=${imagePath}`;

Step 2: Update Existing Product Data

For products already in your system, you can either:

  • Option A: Update the JSON files to use proxy URLs
  • Option B: Convert URLs dynamically in your JavaScript

Step 3: Test the Implementation

Use the test pages to verify everything works:

  • upload-test-images.html - Upload test images
  • test-image-proxy.html - Test proxy functionality

💡 Key Points

  • URL Format: /.netlify/functions/image-proxy?path=productImages/filename.jpg
  • Path Parameter: Use the Firebase Storage path (e.g., productImages/ring-001.jpg)
  • Encoding: URL encode the path parameter for special characters
  • Bandwidth Savings: First user loads from Firebase, subsequent users get CDN cached version
  • Performance: Faster loading times globally due to CDN edge caching
